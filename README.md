# CS Concept Lab

A visual lab for computer science across all themes, with ten algorithm lessons and eight data-structure lessons. Available in English and Egyptian Arabic, with purple-and-gold card animations, theory, and synchronized pseudocode. Built for the @abodbuilds CS concepts series.

```sh
npm run build:web
npm run web
npm run test:web
```

Open http://127.0.0.1:5163 after starting the server, or open the generated `webapp/dist/index.html` offline. The app has no runtime dependencies, backend, or external font requests; the only network request is Plausible's cookieless analytics script.

See [webapp documentation](webapp/README.md), [content themes](THEMES.md), and the [lesson interface](webapp/lessons/CONTRACT.md).

Video-production scripts and episode source files accompany the original lessons. Generated recordings, review exports, credentials, and local settings are excluded from this repository. Alexandria is bundled under its [SIL Open Font License](skills/cs-concept-script/assets/fonts/OFL.txt).
